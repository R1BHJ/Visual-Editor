# Visual-Editor.
Visual Editor &amp; Library Editor — пара инструментов для просмотра/редактирования Pick&amp;Place CSV и создания библиотек корпусов компонентов с поддержкой DXF-фона, Bottom-вида и универсального импорта CSV.
# Visual Editor & Library Editor

Набор из двух настольных программ для работы с **Pick&Place CSV** файлами и **библиотекой корпусов** электронных компонентов.

- **Visual Editor** — просмотр и редактирование Pick&Place CSV на графическом поле: поворот компонентов, наложение DXF-фона, режим Bottom, ручное сопоставление столбцов.
- **Library Editor** — графический редактор библиотеки корпусов `footprints.json`: создание тел, падов, ключа Pin1, диодов, полосы тантала и знаков «+/-».

Обе программы **работают совместно**: Library Editor создаёт и сохраняет `footprints.json`, а Visual Editor использует его для отрисовки компонентов на плате.

## Как программы связаны друг с другом

```
        Library Editor                        Visual Editor
   (редактирование корпусов)              (просмотр/правка P&P)
             │                                     │
             │ сохраняет                            │ читает
             ▼                                     ▼
        footprints.json ──────────────────────── footprints.json
```

1. В **Library Editor** вы создаёте корпуса и сохраняете их в `footprints.json`.
2. В **Visual Editor** загружаете Pick&Place CSV → программа автоматически сопоставляет компоненты с корпусами из `footprints.json` и рисует их на поле.
3. Если поменяли библиотеку, в Visual Editor можно нажать **«Обновить библиотеки»** — компоненты перерисуются без перезапуска.

## Установка из исходников

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-логин>/visual-editor.git
   cd visual-editor
   ```

2. Установите зависимости:
   ```bash
   pip install PyQt5
   ```

3. Убедитесь, что в папке лежат файлы:
   - `visual_editor.py`
   - `library_editor.py`
   - `footprints.json` (создастся автоматически при первом запуске, если отсутствует)
   - `back.png`, `backlib.png` (фоновые картинки, опционально)
   - `icon_left.ico`, `icon_right.ico` (иконки, опционально)

4. Запустите нужную программу:
   ```bash
   py visual_editor.py
   py library_editor.py
   ```

## Сборка .exe

Для распространения без Python используйте PyInstaller:

```bash
pip install pyinstaller

pyinstaller --onefile --console --name Visual_Editor  --icon=icon_right.ico visual_editor.py
pyinstaller --onefile --console --name Library_Editor --icon=icon_right.ico library_editor.py
```

Готовые `.exe` появятся в папке `dist/`.

**Важно:** `.exe` ищут `footprints.json`, картинки и иконки **рядом с самим .exe** (не внутри). Поэтому в одной папке должны лежать:

```
Visual_Editor.exe
Library_Editor.exe
footprints.json
back.png
backlib.png
icon_left.ico
icon_right.ico
```

Тогда обе программы видят **один и тот же** `footprints.json`.

## Visual Editor — как пользоваться

### Основной поток

1. **Открыть CSV** — появится диалог универсального импорта.
2. В диалоге:
   - Выберите **кодировку** (UTF-8, Windows-1251, Windows-1252, Latin-1).
   - Выберите **разделитель** (`;`, `,`, Tab, `|` или свой).
   - При необходимости укажите, **сколько строк пропустить** сверху (если в файле есть шапка/комментарии).
   - Убедитесь, что **превью** внизу показывает правильные данные.
   - Назначьте **столбцы**:
     - **Обязательные:** Component Name, Designator, X, Y, Rotation.
     - **Опциональные:** Footprint, Comment, Layer.
   - Нажмите **OK**.
3. Компоненты появятся на графическом поле.

### Дополнительно

- **Bottom** — включает зеркалирование по X (для BOT-платы). Если загрузили CSV-файл с `bot` в имени — потребуется загрузить DXF и включить Bottom.
- **Загрузить DXF фон** — подкладывает чертёж платы под компоненты.
  - Перемещение DXF — мышью (зажать ЛКМ).
  - Масштаб DXF — `Ctrl + колесо` или `Ctrl + +` / `Ctrl + -`.
  - Сброс масштаба DXF — `Ctrl + 0`.
- **Обновить библиотеки** — перечитывает `footprints.json` и перерисовывает компоненты.
- **Открыть Library Editor** — запускает `Library_Editor.exe` (если он рядом) или `library_editor.py`.
- **Сохранить CSV** / **Сохранить как** — сохраняет текущий CSV со всеми правками (углы, footprint).
- **Обновить CSV** — перечитывает тот же файл заново.

### Правка компонентов

- **ПКМ по компоненту** → контекстное меню: повернуть на ±90°, 180°, задать угол вручную, назначить корпус из библиотеки.
- **Клик по компоненту** — выделяется соответствующая строка в таблице.
- **Клик по строке в таблице** — подсвечивается компонент на поле.
- **Столбец Rotation в таблице** можно редактировать — угол компонента на поле сразу обновится.

## Library Editor — как пользоваться

### Основной поток

1. Слева — список корпусов из `footprints.json`.
2. Выберите корпус или создайте новый (**Новый корпус…**).
3. На рабочем поле справа добавьте элементы корпуса:
   - **Добавить корпус** — тело корпуса (прямоугольник).
   - **Добавить вывод** — одиночный пад.
   - **Добавить матрицу падов** — генератор (BGA, QFN, QFP, SOIC) с настройкой количества, шага, размера, нумерации.
   - **Добавить ключ (Pin1)** — красный кружок (маркер первого вывода).
   - **Добавить диод** — оранжевый треугольник с катодной линией.
   - **Добавить полосу (тантал)** — чёрная полоса (плюсовой торец).
   - **Добавить знак +/-** — знак полярности.
4. Элементы можно:
   - **Перетаскивать мышью**.
   - **Менять размер** — `Ctrl + ЛКМ` и потянуть.
   - **Редактировать через панель справа** (X, Y, ширина, высота, радиус и т.д.).
5. Нажмите **Сохранить всю библиотеку в JSON**, чтобы записать изменения в `footprints.json`.

### Дополнительно

- **Поиск** — фильтр по имени и комментарию.
- **Проверить CSV по библиотеке** — открывает окно, где можно посмотреть, какие `Component Name` из CSV находятся в библиотеке, а какие — «НЕ НАЙДЕН». Дубликаты не выводятся.
- **↶ Отмена (Ctrl+Z)** / **↷ Повтор (Ctrl+Y)** — на панели и по клавишам.
- **Автосохранение** — раз в 3 минуты, если есть несохранённые изменения.
- **Нулевой угол** — угол, на который будет повёрнут корпус относительно CSV-угла на плате (учитывается в Visual Editor).
- **Индивидуальные углы** — можно задать радиус или срез для каждого угла тела корпуса отдельно.

## Формат файла footprints.json

Файл — обычный JSON, где ключ — имя корпуса, значение — его описание:

```json
{
  "0603": {
    "type": "chip",
    "size": [1.6, 0.8],
    "zero_angle_tape": 0,
    "pins": 2,
    "comment": "Резистор/конденсатор 0603",
    "shapes": [
      { "kind": "body", "x": 0.0, "y": 0.0, "w": 1.6, "h": 0.8 },
      { "kind": "pad",  "x": -0.9, "y": 0.0, "w": 0.6, "h": 0.6, "pin": 1 },
      { "kind": "pad",  "x":  0.9, "y": 0.0, "w": 0.6, "h": 0.6, "pin": 2 },
      { "kind": "pin1", "x": -0.6, "y": 0.25, "r": 0.1 }
    ]
  }
}
```

**Типы элементов (`kind`):**

| kind | Описание |
|------|----------|
| `body` | Тело корпуса (может иметь индивидуальные углы, срезы, радиусы) |
| `pad` | Пад (вывод) с номером `pin` |
| `pin1` | Ключ первого вывода (красный кружок) |
| `diode` | Диод (треугольник + катодная линия) |
| `stripe` | Чёрная полоса (тантал) |
| `polarity_sign` | Знак «+» или «−» (`sign`: `"+"` или `"-"`) |

Файл можно править и вручную — обе программы прочитают его корректно.

## Горячие клавиши

### Visual Editor

| Клавиши | Действие |
|---------|----------|
| `Ctrl + колесо` | Масштаб DXF-фона |
| `Ctrl + +` / `Ctrl + −` | Масштаб DXF-фона |
| `Ctrl + 0` | Сброс масштаба DXF |
| ЛКМ по полю | Перетаскивание рабочего поля |
| Колесо | Зум всей сцены (когда CSV загружен) |

### Library Editor

| Клавиши | Действие |
|---------|----------|
| `Ctrl + Z` | Отменить |
| `Ctrl + Y` | Повторить |
| `Ctrl + C` / `Ctrl + V` | Копировать / вставить элемент |
| `Delete` | Удалить выделенный элемент |
| ЛКМ + перетаскивание | Перемещение элемента |
| `Ctrl + ЛКМ` | Изменение размера элемента |

## Частые вопросы

**Программа не видит `footprints.json`.**  
Убедитесь, что файл лежит рядом с `.exe` (или `.py`), а не где-то в другой папке.

**Картинка `back.png` не показывается.**  
Проверьте, что она называется строчными буквами, лежит рядом с программой, и это PNG-файл. В консоли будет строка `[BG] Файл не найден: ...` с полным путём, куда программа искала.

**Компонент не отображается на поле Visual Editor, хотя CSV загружен.**  
В файле в диалоге импорта был неправильно сопоставлен столбец X или Y. Перезагрузите CSV и проверьте маппинг. В консоли будут строки `Warning: Invalid X coordinate in row N`.

**Library Editor не запускается из Visual Editor.**  
Положите `Library_Editor.exe` рядом с `Visual_Editor.exe` (или `library_editor.py` рядом с `visual_editor.py`).

**Как собрать одну программу с моими правками?**  
Просто замените `.py` файлы и пересоберите `.exe` командами из раздела [Сборка .exe](#сборка-exe).
